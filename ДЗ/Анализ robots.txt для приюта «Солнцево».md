## Директивы

- `User-Agent: *` – правило для всех роботов сразу. Отдельных секций для Googlebot или YandexBot нет.
- `Disallow` – закрывает несколько путей. В основном это служебные страницы Tilda:
  - `/page54386855.html`
  - `/header`
  - `/page54515125.html`
  - `/address`
  - `/tilda/form*`
  - `/tilda/rec*`
  - `/tilda/click*`
  - `/tilda/scroll*`
  - `/tilda/popup*`
  - `/tilda/cart*`
  - `/tilda/product*`
  - `/tilda/event*`
  - `/*_escaped_fragment_*`
  
  То есть закрыты технические разделы, корзина, попапы, формы и так далее. Эту директиву понимают и Google, и Яндекс.
- `Sitemap` – указаны три карты сайта:
  - `http://priut-sun.ru/sitemap.xml`
  - `http://priut-sun.ru/sitemap-store.xml`
  - `http://priut-sun.ru/sitemap-feeds.xml`
  
  Поддерживают оба поисковика.
- `Host: priut-sun.ru` – директива Яндекса. Google её игнорирует. Говорит Яндексу, какой домен считать главным (без www). Сейчас считается устаревшей, но Яндекс всё ещё её читает.

## Что для Google, что для Яндекса

- Для Google: стандартные `User-Agent`, `Disallow`, `Sitemap`. `Host` не работает.
- Для Яндекса: те же `Disallow` и `Sitemap`, плюс `Host`. Специальных директив типа `Clean-param` или `Crawl-delay` нет.

## Итог
robots.txt минимальный. Закрывает служебные страницы Tilda, отдаёт карты сайта обоим поисковикам и отдельно указывает хост для Яндекса. Ничего лишнего.

я бы добавила 
- Crawl-delay: 2 – чтобы робот не частил с запросами и не грузил сервер. Полезно для слабого хостинга.
- Clean-param: utm_source&utm_medium&utm_campaign – чтобы страницы с utm-метками не считались дублями. Склеивает одинаковые по смыслу адреса.
- Disallow: /tilda/ – чтобы закрыть всю папку Tilda одной строкой. Там служебные страницы, в индексе им делать нечего.
- Sitemap: https://priut-sun.ru/sitemap.xml – чтобы отдать карту сайта по https. Если сайт работает по https, так надёжнее.
- User-Agent: SemrushBot + Disallow: / – чтобы запретить конкретному боту обход сайта. То же для AhrefsBot и MJ12bot. Они не нужны, только нагрузку создают.
- Host – можно убрать. Она устарела, использовалась для указания главного зеркала для Яндекса. Сейчас почти не работает.
