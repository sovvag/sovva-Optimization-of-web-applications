
> [!note] **Определение**  
> **Веб-приложение** — это приложение, построенное по архитектуре «клиент-сервер», где в качестве клиента выступает веб-браузер, а взаимодействие происходит по протоколу HTTP с веб-сервером.

## Примеры веб-приложений
- Поисковые системы ([[Яндекс]], Google)
- Открытые энциклопедии ([[Википедия]])
- Видео-коллекции (YouTube)
- Новостные системы

## Веб-стандарты и их роль

> **Веб-стандарты** — это открытые, не защищённые патентами спецификации и рекомендации консорциума **W3C** (World Wide Web Consortium).  
> W3C — организация, разрабатывающая и внедряющая технологические стандарты для Интернета.

### Причины использования стандартов
1. **Эффективность кода** — меньше ошибок, быстрее загрузка.
2. **Лёгкость сопровождения** — проще вносить изменения.
3. **Совместимость с устройствами** — от ПК до смартфонов.
4. **Дружелюбность к веб-роботам** — лучше индексация поисковиками.

## Этапы разработки веб-сайта
1. **Подготовительный** — анализ, цели, ЦА, ТЗ.
2. **Разработка макета** — графическое представление.
3. **Вёрстка** — создание HTML/CSS кода.
4. **Программирование и установка CMS**.
5. **Наполнение контентом**.
6. **Публикация в интернете** (домен + хостинг).
7. **Раскрутка сайта** (SEO, реклама).
8. **Администрирование и поддержка**.

## Макет и вёрстка

> **Макет (шаблон)** — графическое представление сайта.  
> **Вёрстка** — процесс формирования страниц путём компоновки текстовых, графических и прочих элементов, создание кода на **HTML** и **CSS**.

### Требования к вёрстке
- **Кроссбраузерность** — корректный вид во всех браузерах.
- **Гибкость** — адаптация под разные экраны.
- **Быстрота обработки** браузером.
- **Валидность** — соответствие стандартам W3C.
- **Семантическая корректность** — логичное использование HTML-элементов.

---

## Виды вёрстки

### 1. Табличная
- Использует таблицы с невидимой границей.

| **Плюсы** | **Минусы** |
|-----------|------------|
| Простота и быстрота | Долгая загрузка |
| Корректное отображение в разных браузерах | Громоздкий код |
| | Плохая индексация поисковиками |
| | Нет разделения содержимого и оформления |
| | Несоответствие стандартам |

### 2. Блочная
- Использует слои (блоки `<div>`), которые накладываются друг на друга.

| **Плюсы** | **Минусы** |
|-----------|------------|
| Компактный код, небольшой вес | Сложная вёрстка |
| Отличная индексация | Трудно обеспечить одинаковый вид во всех браузерах |
| Слои можно накладывать | При уменьшении разрешения блоки «съезжают» |
| Быстрая загрузка | |

## Типы вёрстки по адаптивности

| Тип | Описание | Плюсы | Минусы |
|-----|----------|-------|--------|
| **Фиксированная** | Чёткая структура в пикселях | Дизайн «до пикселя» | «Всё бежит» при изменении размера окна |
| **Резиновая** | Ширина в процентах, адаптируется | Подходит под любой экран | Нестабильность дизайна |
| **Гибридная** | Сочетание фиксированной и резиновой | Компромисс | Сложнее реализовать |

## Контент и SEO

> **Тематический индекс цитирования (тИЦ)** — технология Яндекса для определения авторитетности сайта по качеству и тематической близости ссылающихся ресурсов. Влияет на порядок в каталоге Яндекса.

**Наполнение контентом:**
- Эффективность сайта напрямую зависит от качества **контента** (текст, графика).
- Используется **SEO-копирайтинг** — создание текстов с учётом восприятия пользователем и требований поисковых систем.

## Публикация в интернете

> **Доменное имя** — уникальный набор символов, идентифицирующий ресурс.  
> **Регистраторы** — организации, занимающиеся регистрацией доменов и координацией DNS.

> **Хостинг** — услуга по предоставлению дискового пространства для размещения сайта.

### Виды хостинга
| Тип | Описание |
|-----|----------|
| **UNIX-хостинг** | На базе Linux/Unix |
| **Windows-хостинг** | На базе Windows Server |
| **Виртуальный сервер** | Общий сервер, но изолированное окружение |
| **Виртуальный выделенный сервер (VDS)** | Собственные лимиты ресурсов |
| **Выделенный сервер** | Полный доступ, вы отвечаете за всё |
| **Co-location** | Ваше оборудование в дата-центре |

### Критерии выбора хостинга
- Технические характеристики
- Загруженность канала
- Служба поддержки
- Доступность 24/7
- Объём трафика
- Стоимость (без скрытых платежей)
- Возможность размещения редких сайтов

## Поддержка и типы сайтов

### Классификация сайтов

#### По назначению
- **Личный сайт** (портфолио, блог)
- **Бизнес-сайт** (продажи, привлечение клиентов)
- **Промо-сайт** (к выходу продукта/события)
- **Сайты электронной коммерции** (интернет-магазины, платёжные системы, обменники)
- **Информационные порталы**
- **Сайты для общения** (форумы, соцсети)
- **Сайты специального назначения**

#### Информационные порталы
- **Новостные** — оперативная информация
- **Тематические** — узкая тематика
- **Доски объявлений** (Avito)
- **Файловые архивы** (сборники терминов, файлов)
- **Wiki-энциклопедии**

#### Сайты специального назначения
- **WAP-сайты** — для мобильных устройств (используют язык WML)
- **Поисковые системы** (поиск по запросу)
- **Каталоги и рубрикаторы**:
  - Общетематические
  - Тематические
  - Специализированные
- **Рейтинги и системы статистики**
- **Почтовые веб-сервисы**
