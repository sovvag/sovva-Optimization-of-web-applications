# Lens & Look

Интернет-магазин оптики и контактных линз. Сайт написан на PHP и использует базу данных MySQL, поэтому для запуска его нужно развернуть на локальном сервере, в моем случае в Open Server.

## Как развернуть на Open Server

1. Скачать проект и положить папку в `OSPanel\domains\`, назвав её `lens`. Сайт будет открываться по адресу `http://lens/`.
2. В Open Server выбрать PHP 7.4 или новее и MySQL 8.0, затем запустить сервер.
3. Открыть phpMyAdmin (пользователь `root`, пароль пустой), создать базу `lens_look` и импортировать в неё файл `sql/database.sql`.
4. Открыть в браузере `http://lens/`.

## Подключение к базе данных

Параметры подключения указаны в файле `includes/db.php`:

```php
$host = 'localhost';
$dbname = 'lens_look';
$user = 'root';
$pass = '';
```

Если данные для MySQL на компьютере другие, их нужно изменить в этом файле.
