# Лабораторная работа №6 - Системы аналитики (Google Analytics, Яндекс.Метрика)

1\. Теория

**Системы веб-аналитики** — инструменты, которые позволяют собирать, анализировать и визуализировать данные о поведении пользователей на сайте.

1.1. Основные цели аналитики

- Анализ источников трафика
- Понимание пользовательского поведения
- Измерение эффективности маркетинга
- Отслеживание конверсий

1.2. Популярные системы аналитики

- **Google Analytics 4 (GA4)** — гибкий инструмент аналитики от Google
- **Яндекс.Метрика** — распространённый инструмент в РФ, интегрирован с Яндекс.Директ

1.3. Ключевые метрики

- Посетители / Просмотры
- Сессии
- Показатель отказов
- Глубина просмотра
- Время на сайте
- Конверсии

2\. Задания

2.0. Подготовительный этап.

Использовать сайт из ЛР3 (my-site).

2.1. Подключение Google Analytics 4 (GA4)

1.  Перейти на [https://analytics.google.com](https://analytics.google.com/)
2.  Создать веб-ресурс
3.  Указать адрес сайта (например, GitHub Pages)
4.  Скопировать и вставить скрипт gtag.js в &lt;head&gt; всех страниц

2.2. Подключение Яндекс.Метрики

1.  Перейти на [https://metrika.yandex.ru](https://metrika.yandex.ru/)
2.  Создать счётчик
3.  Указать домен
4.  Вставить код Метрики в &lt;head&gt; или &lt;body&gt; всех страниц

2.3. Настройка цели

- Тип: **переход на страницу** /contacts.html
- Цель в обеих системах — _Destination Goal_

2.4. Имитация трафика

- открыть сайт в браузере;
- переходить между страницами;
- выполнить псевдо-конверсии (регистрации, переходы).

2.5. Анализ данных

- Проверить количество сессий
- Источники трафика
- Страницы, которые просматривали больше всего
- Количество достигнутых целей
- Сделать скриншоты отчётов

2.6. Сравнение GA4 и Метрики

| **Критерий** | **GA4** | **Яндекс.Метрика** |
| --- | --- | --- |
| Интерфейс | сложнее, гибкий | проще, интуитивный |
| Интеграция с рекламой | Google Ads | Яндекс.Директ |
| Доступность | доступна везде | может быть ограничена |
