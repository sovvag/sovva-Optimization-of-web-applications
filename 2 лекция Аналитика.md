SWOT
s - сильные стороны
w - слабые стороны
o - возможности
t - угрозы
so - реализация через сильные стороны
st - использование сильных сторон для нейтрализации угроз
wo - использование возможностей для минимизации слабых сторон
wt - минимизация рисков на стыке угроз и слабостей

| внутренние внешние факторы | возможжности | угрозы |
| -------------------------- | ------------ | ------ |
| сильные стороны            | стратегия SO | ST     |
| слабые стороны             | WO           | WT     |
