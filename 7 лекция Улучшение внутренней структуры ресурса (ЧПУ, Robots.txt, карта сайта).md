## Основные преимущества ЧПУ адресов:
1. В адресе можно использовать ключевые слова, что положительно влияет на ранжирование страницы  
﻿﻿2. Естественные ссылки в виде адресов страниц также передают вес по необходимым ключевым словам, содержащимся в ЧПУ  
﻿﻿3. Улучшается кликабельность сниппетов в выдаче, т.к. ключевые слова подсвечиваются в поиске и привлекают больше внимания
﻿﻿4. Облегчает запоминание адресов страниц
5. Помогает узнать, о чем страница еще до перехода по ссылке, что уменьшает показатель отказа и помогает привлекать более целевых посетителей
6. Упрощает навигацию по сайту
7. ЧПУ снижает вероятность появление внутренних дублей
8. Упрощают работу с веб-аналитикой

> **Сниппет** (snippet - отрывок) – краткая информация о странице, которая располагается в выдаче поисковых систем и позволяет оценить содержание без непосредственного перехода на сайт

### Какие ошибки допускаются при использовании

**ЧПУ-адресов:**

• пробелы и служебные символы
• слишком длинные ЧПУ-адреса
• цифровые значения в ЧПУ-адресе
• использование не значимых слов

### Файл robots.txt

> **Robots.txt** - это текстовый файл, который содержит параметры индексирования сайта для роботов поисковых систем

Например, на сайте www.example.com адрес
файла robots.txt будет выглядеть как www.example.com/robots.txt


### Правила в отношении формата и расположения файла

1. Файл должен носить название **robots.txt!!!**
2. На сайте должен быть только один такой файл
3. Файл robots.txt нужно разместить в корневом каталоге сайта
4. Файл robots.txt можно добавлять по адресам с субдоменами или нестандартными портами
5. Комментарием считается любой текст после символа #

### Синтаксис файла
1. Файл robots.txt должен представлять собой текстовый файл в кодировке UTF-8
2. Файл robots.txt состоит из групп (директив)
3. Каждая группа может содержать несколько **правил**, по одному на строку
4. Группа включает следующую информацию:

	– К какому **агенту пользователя** применяются директивы группы.
	– К каким каталогам или файлам у этого агента есть доступ.
	– К каким каталогам или файлам у этого агента нет доступа.

5. Инструкции групп считываются сверху вниз.
6. **По умолчанию предполагается**, что если доступ к странице или каталогу не заблокирован правилом Disallow:, то агент пользователя может их обрабатывать
7. Правила **чувствительны к регистру**

> **Disallow** – директива, запрещающая индексирование отдельных страниц, групп страниц, их отдельных файлов и разделов сайта(папок). 

Это наиболее часто используемая директива, которая исключает из индекса:

- страницы с результатами поиска на сайте;
- страницы посещаемости ресурса;
- дубли;
- сервисные страницы баз данных;
- различные логи;
- страницы, содержащие персональные данные пользователей.
